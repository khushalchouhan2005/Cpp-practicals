# C++ Programming Practicals — Part D (45–63)

Classes, objects and operator overloading.

45. Function overloading in member functions of a class.
46. Add two complex numbers, passing objects by reference and returning by value.
47. Find the mean of two numbers belonging to two different classes using a friend function.
48. Add two arrays using a friend function and operator overloading.
49. Overloaded constructors to dynamically allocate an array and find its largest element.
50. Dynamic constructor to allocate an array and count even and odd elements.
51. Overload increment and decrement operators for an array class.
52. Find the next date using the unary increment operator.
53. Demonstrate type conversion using a distance class.
54. Unary operator overloading using a member function.
55. Unary operator overloading using a friend function.
56. Binary operator overloading using a member function.
57. Binary operator overloading using a friend function.
58. Basic-to-object type conversion.
59. Object-to-basic type conversion.
60. Class-to-class type conversion.
61. Single inheritance.
62. Multiple inheritance.
63. Inheritance using a Bill base class and cash/cheque payment derived classes.

## Compile and run
Compile each `.cpp` file separately. Example on Windows:
```bash
g++ 45_function_overloading_member_functions.cpp -o program.exe
program.exe
```

Note: Practical 51 increments/decrements every array element. Practical 53 demonstrates both basic-to-class and class-to-basic conversion with a Distance class.
