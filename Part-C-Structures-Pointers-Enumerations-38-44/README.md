# C++ Programming Practicals — Part C (38–44)

Structures, pointers and enumerations.

38. Read and display student information using a nested structure.
39. Read and display the information of all students in a class.
40. Use a pointer to a structure to initialize its members.
41. Illustrate the use of arrays within a structure.
42. Display the names of colors using enumerated types.
43. Enter a rational number, simplify it, and display the result.
44. Display students in descending order of their marks.

## Compile and run
Compile each `.cpp` file separately. Example on Windows:
```bash
g++ 38_student_info_nested_structure.cpp -o program.exe
program.exe
```
