## ▶️ How to Compile and Run

Each `.cpp` file is an independent program and should be compiled separately.

### Using GCC (g++)

**Step 1:** Open the terminal in the folder containing your program.

**Step 2:** Compile the program:

```bash
g++ filename.cpp -o program.exe
```

**Step 3:** Run the executable:

```bash
program.exe
```

For example:

```bash
g++ 01_distance_between_points.cpp -o program.exe
program.exe
```
