# C++ Programming Practicals — Part F (79–96)

File Handling, Templates and Exception Handling.

79. Create a file and write data into it.
80. Read and display the contents of a file.
81. Append data to an existing file.
82. Open and close files using file stream classes.
83. Detect the end-of-file while reading a file.
84. Demonstrate different file opening modes.
85. Demonstrate file pointers using `seekg()`, `seekp()`, `tellg()` and `tellp()`.
86. Implement a function template.
87. Implement a class template.
88. Implement a class template with a friend function.
89. Demonstrate static variables in class templates.
90. Implement a function template with multiple data types.
91. Implement exception handling using `try`, `throw` and `catch`.
92. Demonstrate exception handling using multiple catch statements.
93. Implement a catch-all exception handler.
94. Demonstrate exception handling in an invoked function.
95. Implement exception handling for division by zero.
96. Implement exception handling for invalid input.

## Compile and run
Compile each `.cpp` file separately. Example on Windows:
```bash
g++ 79_create_file_and_write_data.cpp -o program.exe
program.exe
```

**Note:** Practicals 80 and 81 use `sample.txt`. Run Practical 79 first to create the file.
