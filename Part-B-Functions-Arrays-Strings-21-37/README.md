# C++ Programming Practicals — Part B (21–37)

Functions, arrays, strings and pointers.

21. Calculate x^y using recursion.
22. Generate and display random numbers using an array.
23. Interchange the largest and smallest array elements.
24. Find the second-largest distinct element.
25. Merge two unsorted arrays.
26. Implement linear search.
27. Find the transpose of a 3x3 matrix.
28. Read and display a 2x2x2 array.
29. Concatenate two strings.
30. Compare two strings.
31. Insert a string at a specified position.
32. Sort student names alphabetically.
33. Display n lines starting from the m-th line.
34. Add two integers using pointers.
35. Add two vectors represented by arrays.
36. Copy a string using dynamically allocated memory.
37. Read, display, add and subtract two complex numbers.

Compile each `.cpp` file separately. Example on Windows:
```bash
g++ 21_power_using_recursion.cpp -o program.exe
program.exe
```
