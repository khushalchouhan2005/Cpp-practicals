# C++ Programming Practicals — Part A (1–20)

This folder contains the first 20 programs from the supplied C++ lab practical list.

## How to compile and run
Using g++:
```bash
g++ 01_distance_between_points.cpp -o program
./program
```
On Windows, run:
```bash
g++ 01_distance_between_points.cpp -o program.exe
program.exe
```

Each `.cpp` file is a separate program and should be compiled individually.
